Desarrollo sobre PI System

Software a medida, construido sobre sus datos PI.

Cuando las herramientas estándar no alcanzan, desarrollamos sobre la plataforma que usted ya tiene: símbolos, aplicaciones web y automatizaciones que leen y escriben en PI de forma gobernada.

PI Web API · ejemplo 
// Movimiento del turno desde Asset Framework
GET /piwebapi/streamsets/{webId}/value
    ?nameFilter=Movimiento*

// respuesta
{
  "Name": "Movimiento_Total",
  "Value": 96.4,
  "UnitsAbbreviation": "kt",
  "Good": true
}

Cada aplicación consume el mismo modelo AF que usa PI Vision. Un solo dato, una sola verdad.
